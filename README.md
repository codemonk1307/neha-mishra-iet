# Portfolio - Neha Mishra

A modern, responsive portfolio website showcasing professional achievements, technical expertise, and creative pursuits.

## Features

- **Responsive Design** - Optimized for all devices and screen sizes
- **Interactive Animations** - Smooth AOS animations and particle effects
- **Professional Timeline** - Career progression from internships to Salesforce
- **Achievement Showcase** - Hackathon wins and competitive programming accomplishments
- **Creative Section** - Integration of art and stand-up comedy interests

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- AOS (Animate On Scroll)
- Particles.js
- Typed.js

## Sections

- Hero/Landing
- About
- Achievements
- Professional Experience
- Literature & Reading
- Art & Comedy
- Projects
- Contact

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. Or serve using any static server
